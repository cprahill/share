# BUILD 113 — four-mode core

Home is TIME TRIAL, TOUR, EXPLORER, FREESTYLE. RAID stays in the URL for old links.

**TIME TRIAL** — no coins, extra boosts. CPU plus ghosts of your best and the board's top 3. Challenge links fill a common board.

**TOUR** — coins + time vs CPU. Phantom of the fastest shared tour (or trial) run if one exists.

**EXPLORER** — open-course photo scavenger. Unchanged hunt.

**FREESTYLE** — jump playground on the ribbon. Extra kickers (`PLAY_JUMPS`), more boosts, faster, longer air. No clock, no finish. Race JUMPS / path / sit / pad untouched.

Moon and Earth can reuse this same four-mode core later.
