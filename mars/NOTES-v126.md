# BUILD 126 — fullscreen + fit the visible screen

Share on a phone was clipped by Safari chrome, and there was no fullscreen control. iPhone has no page Fullscreen API.

**Fit**
- Canvas, HUD, and touch pads size to `visualViewport` (the pixels you can actually see).
- Home, boot, how, scores, and finish scroll inside `100svh` so they are not cut off.

**FULL**
- Corner **FULL** / home **FULL SCREEN**. Desktop/Android: Fullscreen API. iPhone: fit-to-visible-view (`fs-fit`).
- Pixel ratio cap 1.15 mobile / 1.75 desktop.

JUMPS / path / sit / pad / dunes / hunt slots untouched vs 125.
