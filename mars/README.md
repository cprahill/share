# RED DUST BAJA — internal playable prototype

Internal only. Tesla / Cybertruck / Starship likeness cannot ship without rights. Do not post.

## Run

cd /workspace/project-mars/playable
python3 -m http.server 8765

Open http://127.0.0.1:8765/

## Controls

- WASD / arrows — throttle, brake, steer
- Space — boost (starts full)
- Shift — handbrake
- R — flip recovery, or retry after a lap

No start menu. You drop on the canyon with boost ready.

## Rules

Idle cannot win. Gates only count if you drive through them with speed.

HUD: speed, boost, timer, next gate.
